# React Course Project

A single-page application (SPA) developed as part of the React intensive course at [learn.javascript.ru](https://learn.javascript.ru/courses/react).

The goal of this project is to master the modern React ecosystem, component architecture, and web development best practices.

- **Core:** React, JavaScript
- **State Management:** Redux Toolkit
- **Tooling:** Vite, ESLint, Prettier
